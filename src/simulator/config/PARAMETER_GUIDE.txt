MVTGO2 Continuous Rally 正式參數索引
======================================

用途
----
本資料夾集中 R1～R6 Continuous Rally 正式執行時使用的數值參數。
開發者修改參數後，應以固定 Seed 重新建立 Simulator／Session，不可在 Rally 執行途中熱套用。

本次只移動參數來源，沒有改變數值、運算順序或 RNG 呼叫順序。
原模組仍保留既有 export 名稱，供既有測試與其他模組相容使用。

單位
----
- world px：Simulator 世界座標，世界尺寸 2280 × 900。
- 秒：模擬時間，不是 requestAnimationFrame frame 數。
- world px/s、world px/s²：世界座標速度與加速度。
- 權重／機率：除特別標示百分比外，依呼叫端正規化。

尚未遷移
--------

1. Formation V4、Rotation／Job、五種攻擊 READY／ATTACK
   - 原因：屬定義型資料，不是一般數值參數；本階段明確禁止修改座標轉換。

2. SPIKE_COURT_V1（球場 polygon、bounds、netX、netHeight）
   - 原因：polygon、Formation 合法區與 HOME/AWAY 轉換高度耦合。
   - netHeight=160 仍為暫定 V1；應在定義資料集中化階段一起處理。

3. PASS_TARGET_ZONES_V1
   - 原因：屬一傳區域定義，並由視覺 Editor 使用；不能只搬數值而留下第二份 Editor 預設。

4. receive-animation.js 與 camera-controller.js
   - 原因：純顯示／觀感參數；本階段不得修改 Renderer。

5. 舊 match/match-resolver.js 的 TEMPORARY_SERVE_RESOLUTION
   - 原因：首頁舊 Match 專屬，不參與 Continuous Rally；依任務要求不搬遷。

6. TEAM_RECEIVE_FORMATION 的測試球員能力、morale 與 serveType 派生
   - 原因：屬暫時測試 roster，不是比賽參數；等待正式球員輸入 Adapter。

7. r1-job-coordination.js 的 legacy RIGHT_DEFENSE_POINTS 與攔網 lane offset
   - 原因：前者是相容 fallback，正式 Rally 優先使用 Formation V4 DEFENSE；後者與工作定義及球場方向耦合。

8. 單人、D2、single-defense、third-pass 等獨立實驗 defaults
   - 原因：不屬 R1～R6 Continuous Rally 正式參數。


修改後最低驗證
------------

1. node --check 所有 config 及修改模組。
2. receive、serve、attack-resolution、attack-motion、block 測試。
3. Continuous Rally／Session、R1 Attack Plan、R1～R6 rotation 測試。
4. 1,000 Seed × 30／60／144 FPS 壓力測試。
5. git diff --check。

若固定 Seed 的事件序列改變，應回復並定位引用差異，不可用調整參數值修補測試。
